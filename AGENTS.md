# Riffing on Software

An Astro-based static blog deployed to Cloudflare Pages.

## Quick Reference

- Package manager: Bun
- Dev: `bun run dev`
- Build: `bun run build`
- Format: `bun run format`
- Format check: `bun run format:check`
- Typecheck: `bun run typecheck`
- Main branch: `trunk`
